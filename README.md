## 📱 Описание проекта

Приложение поддерживает автомобили серии Geely Galaxy (Galaxy E5, Galaxy L6/L7), а также совместимые с системой YunOS автомобили. Поддерживает одновременную видеозапись и фотосъёмку с **до 4 камер**, удалённое управление через **DingTalk**, **Telegram** и **Feishu**.

### ✨ Основные возможности

- 🎨 **FlymeAuto-подобный интерфейс** - Элегантный дизайн с погруженной строкой состояния, оптимизирован для в-машинного использования
- 🎥 **Видеозапись и фотосъёмка** - Синхронная многокамерная запись и снимки в реальном времени с выбором активных камер
- 👁️ **Удалённый мониторинг** - Просмотр камер через DingTalk, Telegram и Feishu
- 🚫 **Без ограничения по скорости** - Запись доступна в любой момент, независимо от скорости автомобиля
- 🔄 **Автозапуск и фоновое сохранение** - Многоуровневая система: автозапуск + фоновый сервис + WorkManager + служба доступности
- 💾 **Поддержка множественных мест хранения** - Внутренняя память и USB-накопитель с автоматической очисткой старых файлов
- 🎬 **Сегментированная запись** - Автоматическое разделение видео на сегменты (1/3/5 минут)
- ⏱️ **Водяной знак временной метки** - Опциональное добавление временной отметки на видео и фотографии
- 🖼️ **Плавающее окно** - Настраиваемая кнопка с указанием статуса записи в реальном времени
- 🌙 **Запись при отключенном экране** - Продолжение записи после блокировки экрана
- 🔧 **Поддержка множественных моделей** - E5, E5-Multi-Button, L6/L7, L7-Multi-Button, телефон и кастомные конфигурации

## 🛠️ Технический стек

- **Язык**: Java
- **Минимальная версия**: Android 9.0 (API 28)
- **Целевая версия**: Android 14+ (API 36)
- **API камер**: Camera2 API
- **Кодирование видео**: MediaRecorder (аппаратное) / OpenGL + MediaCodec (программное)
- **Сборка**: Gradle 8.x (Kotlin DSL)
- **UI компоненты**: Material Design Components
- **Загрузка изображений**: Glide 4.16.0
- **Сетевая библиотека**: OkHttp 4.12.0
- **DingTalk интеграция**: DingTalk Stream SDK 1.3.12
- **Фоновые задачи**: WorkManager 2.9.0

### 🚗 Поддерживаемые модели

| Модель | Камер | Режим записи | Примечания |
|--------|-------|-------------|-----------|
| Galaxy E5 | 4 | MediaRecorder | Стандартная модель |
| Galaxy E5-Multi | 4 | MediaRecorder | Упрощённый интерфейс |
| Galaxy L6/L7 | 4 | OpenGL+MediaCodec | Адаптивный режим |
| Galaxy L7-Multi | 4 | OpenGL+MediaCodec | Упрощённый интерфейс |

## 📦 Быстрый старт

### Требования к окружению

- **JDK**: 17 или выше (рекомендуется JDK 25)
- **Android Studio**: Hedgehog (2023.1.1) или выше
- **Gradle**: 8.0+
- **Тестовое устройство**: Android 9.0+ с несколькими камерами

### Клонирование проекта

```bash
git clone https://github.com/your-username/EVCam.git
cd EVCam
```

### Настройка JDK (Windows)

Проект включает скрипт для настройки JDK 25:

```batch
# Сборка с автоматической настройкой JAVA_HOME
build-with-jdk25.bat
```

Или ручная настройка переменных окружения:

```batch
set JAVA_HOME=C:\Program Files\Java\jdk-25.0.2
set PATH=%JAVA_HOME%\bin;%PATH%
```

### Конфигурация DingTalk

Для использования удалённого управления:

1. Создайте приложение DingTalk (режим Stream)
2. Получите `Client ID` и `Client Secret`
3. Создайте файл `app/src/main/java/com/kooo/evcam/dingtalk/DingTalkConfig.java`:

```java
package com.kooo.evcam.dingtalk;

public class DingTalkConfig {
    // DingTalk учётные данные
    public static final String CLIENT_ID = "ваш Client ID";
    public static final String CLIENT_SECRET = "ваш Client Secret";

    // Конфигурация загрузки
    public static final boolean ENABLE_UPLOAD = true; // Включить загрузку
}
```

**Важно**:
- DingTalk переименовал AppKey/AppSecret в Client ID/Client Secret
- Если не нужен DingTalk, закомментируйте код в `MainActivity.java`

## 📖 Руководство пользователя

### Первый запуск

1. **Выбор модели** - При первом запуске появится экран выбора модели автомобиля (E5/L6/L7/Телефон/Кастом)

2. **Выдача прав доступа** - Используйте менеджер приложений для предоставления всех необходимых разрешений

3. **Предпросмотр камер** - После выдачи прав приложение инициализирует камеры и показывает предпросмотр

4. **Проверка логов** - Нажмите "Показать логи" для проверки статуса инициализации

### Видеозапись

1. Нажмите **"Начать запись"** (или плавающее окно)
2. Все выбранные камеры начинают синхронную запись
3. Видео автоматически разбивается на сегменты (по умолчанию 1 минута)
4. Во время записи можно снимать фото (кнопка "Снимок")
5. Нажмите **"Остановить запись"** для завершения

**Расположение видео**: `/sdcard/DCIM/EVCam_Video/` (или USB)
**Формат имени**: `yyyyMMdd_HHmmss_{position}.mp4` (пример: `20260125_153045_front.mp4`)

### Фотосъёмка

- Нажмите **"Снимок"** в режиме предпросмотра или записи
- Фото захватываются одновременно со всех активных камер
- Может быть добавлена временная метка

**Расположение фото**: `/sdcard/DCIM/EVCam_Photo/` (или USB)
**Формат имени**: `yyyyMMdd_HHmmss_{position}.jpg`

### Просмотр записей

Встроенная функция воспроизведения:

1. Нажмите меню (☰) в левом верхнем углу
2. Выберите **"Видео"** или **"Фото"**
3. Нажмите миниатюру для полноэкранного просмотра
4. Поддерживается множественное удаление

### Плавающее окно

Управление записью из фона:

- **Красная точка** - Запись остановлена
- **Зелёное мигание** - Идёт запись
- **Нажатие** - Открыть приложение
- **Перетаскивание** - Переместить окно

Размер (10 уровней) и прозрачность настраиваются в параметрах.

### Запись при отключённом экране

Для использования блокировочной записи:
- При отключении экрана запись начинается автоматически
- При включении экрана запись останавливается
- Идеально для мониторинга припаркованного автомобиля

### Удалённое управление

После настройки DingTalk доступны команды:

- `Снимок` - Удалённая фотосъёмка и загрузка
- `Запись <секунды>` - Запустить запись на N секунд
- `Статус` - Проверить статус приложения
- `Предпросмотр` - Получить скриншот камеры

### Параметры приложения

Меню → "Параметры":

| Параметр | Описание |
|----------|---------|
| Модель авто | Выбрать модель или кастомизировать камеры |
| Режим записи | Авто/MediaRecorder/OpenGL+MediaCodec |
| Длительность сегмента | 1/3/5 минут |
| Место хранения | Внутренняя память/USB |
| Лимит хранения | Макс. размер видео и фото (ГБ) |
| Камеры для записи | Выбрать активные камеры |
| Плавающее окно | Вкл/выкл, размер, прозрачность |
| Водяной знак | Добавлять временные метки |
| Автозапуск | Запуск при включении телефона |
| Автозапись | Начинать запись при старте |
| Запись на экране блокировки | Продолжить при отключении |
| Фоновый сервис | Защита от завершения |
| Предотвращение сна | Держать устройство в пробуждении |

### Разрешение и битрейт

Меню → "Видео":

- **Разрешение** - Выбрать поддерживаемое камерой
- **Битрейт** - Низкий/Средний/Высокий (влияет на качество и размер)
- **Кадры в сек** - Стандартный/Низкий (снижение уменьшает размер)

### Цвет и фильтры

Главный экран - кнопка "Корректировка":

- Компенсация экспозиции
- Режим баланса белого
- Тональное отображение
- Усиление краёв
- Режим шумоподавления
- Режим эффектов


### Инициализация камер

```
1. Проверка прав → Камера, микрофон, хранилище
2. TextureView готов → Ожидание инициализации
3. Поиск камер → Запрос CameraManager
4. Адаптивная конфигурация → По модели авто:
   - E5: 4 камеры, фиксированный ID
   - L6/L7: 4 камеры, режим Codec
   - Телефон: 2 камеры (передняя/задняя)
   - Кастом: конфигурация пользователя
5. Последовательное открытие → В соответствии с ограничениями ОС
6. Начало превью → Создание CaptureSession
```

### Процесс записи

```
Пользователь нажимает "Начать запись"
    ↓
MultiCameraManager создаёт VideoRecorder для каждой камеры
    ↓
VideoRecorder.prepare() конфигурирует и возвращает Surface
    ↓
SingleCamera добавляет Surface в CaptureSession
    ↓
Синхронный старт → Разбивка на сегменты → Автоматическое создание
    ↓
Пользователь нажимает "Остановить запись"
    ↓
Остановка → Очистка Surface → Восстановление превью
```

### Модель потоков

- **Главный поток**: UI, кнопки, TextureView callback
- **Camera HandlerThread**: Отдельный поток Camera2 API для каждой камеры
- **Codec поток**: Независимый кодировочный поток
- **Logcat поток**: Чтение системных логов
- **DingTalk поток**: WebSocket соединение
- **WorkManager**: Фоновые периодические задачи
- **Очистка хранилища**: Периодическая проверка и удаление

## ❓ Часто задаваемые вопросы

### 1. Камера не открывается

**Возможные причины**:
- TextureView не инициализирован
- Разрешения не выданы (ошибка "Missing permission" в логах)
- Нет доступных камер на устройстве
- Превышен лимит одновременно открытых камер
- Неправильный ID камеры в кастомной конфигурации

**Решение**:
- Убедитесь в срабатывании `onSurfaceTextureAvailable` callback
- Выдайте разрешения в системных параметрах или переустановите приложение
- Проверьте камеры: `adb shell dumpsys media.camera`
- Уменьшите `maxOpenCameras` (по умолчанию 4)
- Проверьте ID камер в кастомной конфигурации

### 2. Запись не работает

**Возможные причины**:
- Директория DCIM/EVCam_Video не доступна для записи
- Камера не открыта или превью не запущено
- Конфигурация MediaRecorder/MediaCodec не совместима
- Недостаточно места на диске
- USB медленно пишет

**Решение**:
- Проверьте разрешение на запись
- Убедитесь, что превью работает перед записью
- Посмотрите ошибки в logcat
- Освободите место или измените лимит хранения
- Для L6/L7 попробуйте изменить режим кодирования

### 3. Изображение не отображается

**Возможные причины**:
- TextureView имеет нулевой размер
- SurfaceTexture недоступна
- Разрешение камеры не поддерживается
- Ошибка Camera2 API

**Решение**:
- Проверьте ширину и высоту TextureView в layout
- Подтвердите вызов `onSurfaceTextureAvailable`
- Проверьте согласование разрешения в логах
- Используйте `adb logcat -s CameraService:V` для системных ошибок

### 4. Приложение закрывается системой

**Решение**:
- Включите фоновый сервис (появится уведомление)
- Отключите оптимизацию батареи в настройках
- Разрешите автозапуск приложения
- Включите службу доступности (Параметры → Доступность → EVCam)
- Включите "Предотвращение сна"

### 5. DingTalk не отвечает

**Возможные причины**:
- Неправильный Client ID/Client Secret
- Нет интернет-соединения
- WebSocket соединение не установлено

**Решение**:
- Проверьте `DingTalkConfig.java`
- Убедитесь в наличии интернета
- Посмотрите статус WebSocket в логах
- Перезагрузите приложение

### 6. Проблемы с USB

**Возможные причины**:
- USB не правильно вставлен или не распознан
- Несовместимая файловая система
- Медленная запись замораживает приложение

**Решение**:
- Проверьте правильность подключения USB
- Используйте FAT32 или exFAT
- Приложение использует буферизацию для медленных USB
- Автоматическое переключение на внутреннюю память при недоступности
